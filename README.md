# บอทแฟม สุภาพสตรี [สตรี]

## ฟีเจอร์
**อัตโนมัติ**
- ต้อนรับสมาชิกพร้อม "ลำดับสมาชิก" (คนเก่าที่กลับมาได้เลขเดิม) / ตั้งชื่อเล่น `[สตรี] ชื่อ` (AUTO_NICKNAME) / ให้ยศอัตโนมัติ (AUTO_ROLE_ID)
- Log (ระบุผู้ทำจาก Audit Log): เข้า-ออก-เตะ, เปลี่ยนชื่อเล่น/ยศ, ข้อความลบ/แก้ไข, ห้องเสียง เข้า-ออก-ย้าย,
  ปิดไมค์/ปิดหู/ตัดการเชื่อมต่อ, Timeout, แบน/ปลดแบน, สร้าง/ลบ/แก้ไขห้อง, เปลี่ยนสิทธิ์ห้อง/ยศ
- ผังแฟมที่อัปเดตเองเมื่อมีการเปลี่ยนยศ

**คำสั่ง Slash** (พิมพ์ `/` ใน Discord)
| คำสั่ง | ใครใช้ได้ | ทำอะไร |
|---|---|---|
| `/ผังแฟม` | ทุกคน | ดูผังโครงสร้างแฟมตามยศปัจจุบัน |
| `/แจ้งก่อน` | ทุกคน | แจ้งลา/ไม่ว่าง (ตั้งแต่-ถึง-เหตุผล) โพสต์ลงห้อง + เก็บประวัติ |
| `/ปักผังแฟม` | ผู้ดูแล | โพสต์ผังไว้ในห้องนี้ และอัปเดตเอง |
| `/ประกาศ` | ผู้ดูแล | เปิดฟอร์มเขียนประกาศ เลือกแท็ก @everyone/ยศได้ |
| `/ลงโทษ` | ผู้ดูแล | ตักเตือน / Timeout / เตะ พร้อมประกาศและเก็บประวัติ |
| `/แบน` | ผู้ดูแล | แบน (มีปุ่มยืนยัน) พร้อมประกาศและเก็บประวัติ |
| `/ปลดแบน` | ผู้ดูแล | ปลดแบนด้วยไอดีผู้ใช้ |
| `/ประวัติ` | ผู้ดูแล | ดูประวัติโทษ/การแจ้งก่อนของสมาชิก |
| `/จัดชื่อแฟม` | ผู้ดูแล | เปลี่ยนชื่อเล่นทุกคนเป็น `[สตรี] ชื่อ` (ลอง `ทดสอบ: true` ก่อน) |
| `/ยศทั้งหมด` | ผู้ดูแล | ดูรายชื่อยศพร้อมไอดี (ไว้ตั้งค่า) |

ผู้ดูแล = เจ้าของเซิร์ฟเวอร์ หรือผู้ที่มียศใน `ADMIN_ROLE_IDS`

## ตั้งค่าครั้งแรก
1. **Supabase**: SQL Editor → รัน `supabase/schema.sql` แล้วรัน `supabase/schema_v2.sql` (รันซ้ำได้)
2. **เชิญบอทใหม่**: Developer Portal → OAuth2 → URL Generator
   - Scopes: ติ๊ก `bot` **และ `applications.commands`** (ขาดอันหลังคำสั่ง / จะไม่ขึ้น)
   - Permissions: View Channels, Send Messages, Embed Links, Read Message History, View Audit Log,
     Manage Nicknames, Kick Members, Ban Members, Moderate Members, Manage Roles, Mention Everyone
   - เปิดลิงก์ที่ได้ เลือกเซิร์ฟเวอร์เดิม → อนุญาต (บอทเดิมจะได้สิทธิ์เพิ่ม)
   - ลากยศบอทให้อยู่ **สูงกว่า** ยศสมาชิกทั้งหมดที่บอทต้องจัดการ (ชื่อเล่น/Timeout/เตะ/แบน/ให้ยศ)
3. ตั้งตัวแปรในแท็บ "สภาพแวดล้อม" ของโฮสต์ (ดูรายการใน `.env.example`)
   ที่ต้องเพิ่มสำหรับเฟสนี้: `ANNOUNCE_CHANNEL_ID`, `NOTICE_CHANNEL_ID`, `PUNISH_CHANNEL_ID` (ห้องที่ประกาศโพสต์),
   `AUTO_ROLE_ID`, และถ้าต้องการเปลี่ยนยศ: `ADMIN_ROLE_IDS`, `CHART_ROLE_IDS` (คั่นด้วยคอมมา)
4. รีสตาร์ตบอท แล้วอ่านคอนโซล: ✅ = ปกติ, ⚠️/❌ = บอกว่าตั้งอะไรผิดหรือขาดสิทธิ์อะไร

## ข้อควรรู้
- ชื่อยศ → ไอดีไว้ตั้งค่า: ใช้คำสั่ง `/ยศทั้งหมด`
- `/แบน` `/ลงโทษ` ใน Audit Log ผู้ทำคือบอท แต่ log ของแฟมจะแสดงชื่อแอดมินที่สั่งจริง
- แบน/Timeout/เตะที่ทำผ่านเมนู Discord ตรงๆ ก็ถูก log เช่นกัน (ผู้ทำมาจาก Audit Log)
- Timeout ที่หมดอายุเอง Discord ไม่ส่งสัญญาณ จึงไม่มี log ตอนหมดเวลา
- ตัดการเชื่อมต่อห้องเสียง: Discord ไม่บอกว่าตัดใคร "ผู้ทำ" จึงเป็นการคาดการณ์
- ข้อความที่ถูกลบ/แก้ไข เห็นเนื้อหาเฉพาะข้อความที่ส่งหลังบอทออนไลน์
- ห้ามแชร์ `DISCORD_TOKEN` / `SUPABASE_SERVICE_KEY` ถ้าหลุดให้ Reset ทันที
